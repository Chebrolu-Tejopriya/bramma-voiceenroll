Developer notes

A thin gradient that listens: short during silence, longer during speech. The curve moves with a subtle drift.

Gradient length

  • Keep the gradient centered and preserve its original stroke thickness.
  • Expand to a maximum of 75% of the visible curve, leaving 12.5% clear at each side.
  • Use voice energy and sustained speech activity to control length. Speech activity is an audio-density cue, not measured words per minute.
  • Use a horizontal CSS mask with 6% fading tails. Change its length only; add no stroke dilation, blur, or dynamic glow.

Motion and timing

Audio smoothing120 ms rise / 380 ms release
Gradient smoothing240 ms expand / 420 ms contract
Curve driftUp to 1.8 px / 550 ms smoothing
Idle breath0.35 px / 7.2 second cycle

Use value += (target - value) * (1 - exp(-dt / tau)), with dt and tau in seconds. This keeps motion consistent across frame rates and avoids overshoot. Translate all curve layers together; keep the timer and button still. Preserve the breathing phase between states.

Word highlighting

Highlight one word at a time with #F8EF8D at 40% opacity. Switch the highlight without a fade and scroll the paragraph internally to keep the current word visible. Pause freezes the reading position; Replay returns to the first word.

States and accessibility

Ready → Listening → Processing → Complete. Settle gently when speech stops. Respect reduced motion by keeping the curve and gradient length still, while preserving word highlighting and the timer.

Implementation files

app.js contains the audio analysis, smoothing and state logic. style.css contains the gradient mask. assets/edge-long.svg preserves the original edge geometry with a gold source; the CSS mask supplies its animated gradient.

Demo and production

Demo voice uses scripted word timings. Microphone mode uses local audio levels and browser speech recognition where available; recognition may use the browser provider’s online service. Voice profile creation and completion are simulated. Connect real completion, retry and error states to your backend.
